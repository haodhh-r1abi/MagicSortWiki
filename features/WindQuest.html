Mô tả

  • Wind Quest xuất hiện trong bộ config server (WindQuestConfigModel) cùng 109 khoá khác, nhưng bản client đang phân tích không chứa bất kỳ class, prefab hay chuỗi nào tên WindQuest.
  • Điều này cho thấy server đã chuẩn bị cấu hình cho một sự kiện sẽ ra mắt ở bản client sau; hiện server để IsEnabled = false nên dù client có code cũng không hiển thị.

Lưu ý

📌 Khi server bật WindQuest và client cập nhật, config chi tiết sẽ về Configs/CachedRemoteConfigs — chạy lại tools/gd_runtime_merge.py để cập nhật trang này.

Mở khóa & điểm vào

FirstLevelToShow = 45 (server), IsEnabled = false (tắt) — đọc từ Firebase RC lúc runtime 2026-09-10.

Cách hoạt động

  1. Chưa xác định được luồng — cần bản client mới có code WindQuest để phân tích tiếp.
Luồng chi tiết theo code

Chưa có luồng trong client 0.0.3063; chỉ có config server. Khi server bật và client cập nhật, cả config chi tiết sẽ về cache Configs/CachedRemoteConfigs.
